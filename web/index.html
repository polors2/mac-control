ONE-TIME SETUP

Give your media
a little freedom.

Brightness, backlight, and sound work already. Sending play, pause, and track keys needs macOS Accessibility access.

  1. On this Mac, open System Settings → Privacy & Security → Accessibility.
  2. Click +, then press ⌘⇧G and choose the helper at the path below.
  3. Enable Mac Control Media. This page will pick up the change automatically.

Media buttons send the standard macOS media key. Your active player decides what plays.

ONE-TIME ADMINISTRATOR SETUP

Input control setup.

The input helper controls the physical built-in keyboard and trackpad separately.

  1. On the host Mac, double-click install-input-helper.command in the Mac Control folder.
  2. Enter your Mac login password in Terminal. Both inputs start enabled.
  3. Return here. The switches become available automatically.

If macOS denies access, open System Settings → Privacy & Security → Input Monitoring and enable Mac Control Inputs. If it is missing, click +, press ⌘⇧G, paste /Library/PrivilegedHelperTools/Mac Control Inputs.app, and add it. Then try the switch again. A restart of the helper or Mac releases disabled inputs. You can also run enable-inputs.command remotely to restore both.

ONE-TIME ADMINISTRATOR SETUP

Enable fan control.

The administrator helper enables Constant, Max, and CPU Target fan modes.

  1. On the host Mac, double-click install-fan-helper.command in the project folder.
  2. Enter your Mac login password in Terminal when requested.
  3. Return here. Constant, Max, and Target become available automatically.

The helper accepts Auto, bounded per-fan Constant RPMs, firmware maximum, and a 50–85°C CPU target. It starts in Auto. Target regulation continues when this page is closed. Your dashboard password is separate from the Mac login password.
